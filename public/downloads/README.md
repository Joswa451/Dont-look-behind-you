The Windows Desktop Edition is distributed as `DontLookBehindYou-Windows-v1.0.1.zip` and the Android edition as `DontLookBehindYou-Android-v1.0.1.apk`. Source archives are kept in `release/windows/` and `release/android/`, then copied into this directory by the production website build. Include both release archives in the deployment repository so the download links serve the actual packages.

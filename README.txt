DON'T LOOK BEHIND YOU — Windows Desktop Edition
Version 1.0.0 | 64-bit Windows | Windows 10 and Windows 11

INSTALL AND PLAY

1. Download DontLookBehindYou-Windows-v1.0.0.zip from the official game website.
2. Right-click the ZIP file and select Extract All.
3. Open the extracted DontLookBehindYou-win folder.
4. Double-click DontLookBehindYou.exe.
5. Start playing. No separate Python or Ren'Py installation is needed.

Keep the extracted folder together. The game executable needs the lib, renpy,
and game folders beside it. Your saves are stored in your Windows user profile.

WINDOWS SECURITY NOTICE

This release is not digitally signed. Windows SmartScreen may show an
unknown-publisher warning. Only continue if you downloaded this ZIP from the
official game website and its SHA-256 matches the value shown there. If you are
unsure, cancel and contact the developer. Do not disable antivirus protection.

TROUBLESHOOTING

• Missing DLL: Extract the complete ZIP again and keep every folder beside the
  EXE. Do not download individual DLL files from third-party sites.
• Game closes immediately: Re-download the ZIP from the official site, extract
  it fully, and check whether your security software quarantined a game file.
• Black screen: Update your graphics driver from your PC or GPU manufacturer's
  official support site. Press Shift+G in the game to open Ren'Py's graphics
  options and try another renderer or windowed mode.
• No audio: Check the game's Preferences volume sliders and Windows' selected
  audio output and volume mixer.
• Insufficient space: Keep at least 2 GB free before extracting the ZIP.
• Antivirus alert: Verify the official SHA-256. If it matches, submit the file
  to your security vendor for review; do not turn off protection.

Controls: click or press Enter/Space to advance dialogue and choose options.
Use the in-game Preferences and Save/Load screens for settings and progress.

Thank you for playing. Don't look behind you.
